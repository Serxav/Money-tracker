# Política de seguridad

## Cómo avisar de una vulnerabilidad

**No abras una issue pública.** Usa el aviso privado de GitHub: pestaña *Security* → *Report a vulnerability* de este repositorio, o escribe a un mantenedor del equipo (ver [README.md](README.md)).

Incluye, si puedes: descripción, pasos para reproducirlo, componente afectado (backend, web o Android) e impacto estimado.

## Qué esperar

- Confirmaremos la recepción lo antes posible.
- Corregiremos el problema antes de divulgarlo.
- Si es una brecha que afecta a datos personales, se seguirá el procedimiento de [SEGURIDAD_Y_ETICA.md](SEGURIDAD_Y_ETICA.md) (notificación en 72 h cuando proceda).

## Alcance

Solo se prueban los entornos propios del proyecto, con permiso del equipo. No se prueba contra sistemas de terceros.

## Versiones soportadas

Mientras el proyecto esté en `0.x`, solo se mantiene la última versión publicada.
