# Versión 0.1.0 — scope

- **Estado:** RC1 (rama `desarrollo/0.1.0/RC1`, tag `v0.1.0-rc.1` al fusionar el PR); QA en Android superada, falta iOS ([informe de QA](0.1.0-qa.md))
- **Fecha de corte:** 2026-10-19
- **Tipo:** alfa de desarrollo (no apta para usuarios reales)
- **Objetivo:** tener el ciclo básico funcionando de punta a punta: registrarse, crear cuentas en cualquier divisa soportada, organizar categorías y anotar ingresos y gastos desde la app de Android e iOS.

## Entra en esta versión

### Backend (Java 21 + Spring Boot 4 + PostgreSQL 17)

| Área | Qué incluye |
|---|---|
| Usuarios y sesión | Registro, login, refresco de sesión con rotación del refresh token, logout, consultar perfil, cambiar divisa principal e idioma |
| Privacidad | Borrar la cuenta con todos sus datos (confirmando la contraseña) |
| Divisas | Lista de divisas soportadas con sus decimales ISO 4217 (EUR, USD, GBP, CHF, JPY, CAD, AUD, MXN, KWD) |
| Cuentas | Crear, listar, ver, renombrar, cambiar saldo inicial y borrar (si no tiene movimientos). Divisa fija por cuenta y saldo calculado |
| Categorías | Categorías de ingreso y gasto por defecto al registrarse; crear, editar y borrar (si no se usan) |
| Movimientos | Crear, ver, editar y borrar ingresos y gastos; listado con filtros (cuenta, categoría, tipo, fechas) y paginación; `Idempotency-Key` para no duplicar |
| Contrato | API `/v1` descrita en `backend/openapi.yaml`, verificada por los tests |

### App móvil (React Native + Expo SDK 58, una base de código para Android e iOS)

| Pantalla | Qué permite |
|---|---|
| Login / Registro | Entrar o crear usuario; la sesión se recuerda de forma segura |
| Inicio | Ver las cuentas con su saldo en su propia divisa |
| Nueva cuenta | Nombre, divisa y saldo inicial |
| Detalle de cuenta | Saldo, movimientos más recientes primero (carga por páginas) y borrar la cuenta |
| Nuevo / editar movimiento | Tipo, cuenta, categoría, importe en la divisa de la cuenta, fecha y descripción; borrar |
| Categorías | Ver por tipo, añadir y borrar |
| Ajustes | Cambiar la divisa principal, cerrar sesión y borrar la cuenta y todos los datos |

### Transversal

- **Seguridad:** Argon2, JWT de 15 min, refresh tokens solo como hash, rate limiting, límite de tamaño, JSON estricto, autorización por propietario (lo ajeno da 404), cabeceras de seguridad, errores sin detalles internos, `X-Request-Id`, tokens de la app en Keychain/Keystore y `allowBackup` desactivado.
- **Dinero:** importes enteros en unidades menores en backend y app; sin coma flotante.
- **Calidad:** 49 tests de backend (unitarios e integración con PostgreSQL real) y 19 de la app; TypeScript estricto, ESLint y `expo-doctor`.
- **CI:** GitHub Actions para backend y app, CodeQL y Dependabot.
- **Documentación:** README de backend y app, ADR 0001-0003, CHANGELOG.

## Limitaciones conocidas

- La fecha del movimiento se escribe como texto `AAAA-MM-DD` (sin selector de fecha).
- Solo en español; paleta provisional hasta la guía de estilo de Pau.
- El registro devuelve un error si el email ya existe (falta verificación por email).
- El rate limiting es en memoria: vale para una sola instancia del backend.
- No hay entornos dev/staging desplegados: todo se prueba en local.

## Compatibilidad

- **API:** `/v1`. Primera versión: no hay clientes anteriores que mantener.
- **Base de datos:** migraciones Flyway V1-V3 sobre una base de datos vacía.
- **Versiones mínimas de Android/iOS:** las de Expo SDK 58 (pendiente fijarlas explícitamente).
